# INF201 Deliverable 2: Campus Coffee Shop Sales Pipeline

Authors: Sanji Miller and Sajjad Ahmadi

## How to run
1. Create a virtual environment: `python -m venv .venv`
2. Activate it: `.venv\Scripts\activate`
3. Install packages: `python -m pip install -r requirements.txt`
4. Generate the input data: `python generate_data_for_d2.py`
5. Open `deliverable_2.ipynb` and run all cells.
